"JAB YAAD AAUN" — Muskan ke liye ek chhoti si website
=======================================================

WHAT'S INSIDE (5 pages)
  index.html      Ghar / Home — welcome page
  reasons.html    Wajah — flip cards, Hinglish shayari couplets on why it's her
  comfort.html    Sukoon — comforting lines + breathing animation for when she misses you
  playlist.html   Gaane — "our songs" list
  letter.html     Khat — final page, click the envelope to reveal a Hinglish shayari letter
  style.css       Shared design (soft pastel pink/cream theme)
  script.js       Shared behavior (floating hearts, nav, flip cards, envelope, heart-burst taps)
  images/         Empty folder if you want to add real photos anywhere later

NAMES ALREADY IN PLACE
  Her: Muskan
  You: Navneet
  These are already written into every page's nav, footer, and letter signature.
  Search-and-replace them if you ever want to change either name.

HOW TO PERSONALIZE IT FURTHER
  1. Open any .html file in a text editor (Notepad, TextEdit, VS Code, etc).
  2. Anything in [brackets] is still a placeholder — especially:
     - reasons.html: cards 03 and 06 are blank for your own reason/memory
     - comfort.html: item 6, the "countdown" line
     - playlist.html: all five songs
     - letter.html: the middle paragraph in [brackets] — this is the most
       important edit. Write what you'd actually say to her, in your own words.
  3. To make a song playable, wrap its title in a link — there's a comment
     near the bottom of playlist.html showing the exact code to paste.

HOW TO VIEW IT
  Double-click index.html and it opens in your browser. The top nav
  (Ghar · Wajah · Sukoon · Gaane · Khat) links every page together.

HOW TO SHARE IT WITH MUSKAN (pick one)
  A) Easiest — zip the whole folder and send it to her. She unzips it and
     double-clicks index.html. Works offline, no setup.
  B) Free live link with GitHub Pages:
     1. Create a free GitHub account and a new repository.
     2. Upload all these files to it.
     3. In the repo's Settings → Pages, set the source to the main branch.
     4. GitHub gives you a live link (yourname.github.io/repo) to send her.
  C) Netlify Drop (netlify.com/drop) — drag the whole folder onto the page
     and it gives you a live link in seconds, no account needed.

A FEW IDEAS
  - Add a page back (Memories or Our Story) any time — copy an existing
    .html file, change its content, and add a link to it in the nav
    list on every page (it's the same <ul class="nav-links"> block).
  - The color palette lives in style.css under :root — nudge the hex
    values there if you want a different pastel mood.
  - Record a short voice note reading the letter out loud and link to
    it from letter.html for an extra touch.

Baaki sab, ab tumhara kaam hai — jitna ho sake, apne alfaaz daal dena.
